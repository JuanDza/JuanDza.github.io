Privacy Policy: Personal Mail MCP

Last updated: 2026-09-19

Who uses it

Personal Mail MCP is used only by its owner, on the owner's own Gmail accounts. It is not offered to the public.

What data it accesses

With the owner's consent, it accesses Gmail messages, labels, drafts and basic mail settings, and the account's email address and profile name, through the Gmail API.

How the data is used

Data is used only to carry out the owner's own requests: searching, reading, drafting, replying to and organizing the owner's mail. It is not used for advertising, profiling or any other purpose.

Storage and sharing

Sign-in tokens are stored only on the owner's own computer. The tool itself keeps no copy of mail content; attachments are saved to the owner's computer only when the owner asks.

To carry out a request, the mail content involved is sent to the owner's AI assistant provider (Anthropic, maker of Claude) under the owner's own account, and to no one else. Data is never sold, and is not shared with or transferred to any other party.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
